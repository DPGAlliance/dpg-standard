# Changelog — DPGs for AI Collection criteria

All notable changes to the DPGs for AI [`criteria.md`](./criteria.md) are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this collection's criteria aim to follow [Semantic Versioning](https://semver.org/) (MAJOR = a change to which criteria are mandatory; MINOR = added/clarified recommended criteria or evidence; PATCH = editorial fixes).

## [Unreleased]

- Open for community input via pull request. No changes merged yet.

## [0.1.0] — Draft

### Added

- Initial public draft of the DPGs for AI technical criteria, published for community review.
- Layered assessment model: Layer 1 (DPG Registry prerequisite), Layer 2 (AI-relevance gate), Layer 3 (category-specific technical criteria).
- Mandatory criteria for **open source software** (S1–S3), **open data** (D1–D3), and **open AI systems** (A1–A3), each with recommended best practices.
- "Beyond DPG Standard/Maturity" notes clarifying how each criterion complements, rather than duplicates, the DPG Standard and the DPG Maturity Model.
